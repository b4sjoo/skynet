## 核心原则（先读这五条）

1. **规则先于数据**：评分卡、权重、kill criteria、风险标签在采集任何数据之前定稿并经用户确认（Stage 0 产出 rubric.md）。
2. **Glass-box**：每阶段落盘 + 报告计数 delta；被 kill 的候选保留在表中并标注原因——类别静默消失 = bug。
3. **活体对照优先**：同款打法现存执行者的实测流量 > 一切词量推算；「别人跑过且归零」是最硬的阴性证据（先例：50 州加班计算器 pSEO ≈0 流量、EMD 域名 19 个月 30 访问/月）。
4. **否决线写在动工之前，触发即执行**：conditional-go 的含义是「先用最便宜的方式把条件变成已知」。实例：移民集群在注册公司前先做竞品流量 kill-check，命中否决线，$0 止损（省下 LLC + 审批流程 + 数周工程）。
5. **结论的单位是「意图结构 × 变现结构」，不是流量体量**：4629 万/月的词族照样 no-go。

## 四阶段漏斗

| 阶段 | 动作 | 关键纪律 |
|---|---|---|
| **Stage 0 定标** | 六维评分卡（参考权重：AI 抗性 25 / 体量 20 / SERP 弱度 20 / RPM 15 / 建造成本 10 / 增长循环 10）+ 硬 kill criteria + 风险标签体系（不计分、只披露） | 与用户对齐后冻结；风险口味交给标签而非隐性过滤 |
| **Stage 1 广撒网** | 10–12 个模态并行挖掘（种子扩展 / 模式枚举 / 社区痛点挖掘 / 高流量老站反查 / 跨语言双向套利 / 官僚摩擦盘点…），每候选必须附真实搜索到的 evidence，宁缺毋滥 | 末端**只去重不筛选**；跨模态被 ≥2 次独立发现本身是需求信号 |
| **Stage 2 量化** | 关键词计划（目标语言的**真实用户查询词**，绝不是项目名；受众在墙内的标 google_unreachable 单列）→ 批量拉 量/CPC/SERP/AI Overview → 机械公式打分 | **矩阵形候选必须做长尾扩展重测**（头词抽样低估 10–100x）；扩展结果存 raw/filtered 双口径供抽查 |
| **Stage 3 对抗性尽调** | 每单元一个 agent，brief 核心句：「你的任务不是推销，是先尽全力找出它会失败的理由」。必查：SERP 前排逐席拆解+各自变现方式、数据源/授权实测（curl/DNS 级）、活体对照流量、当地 RPM 口径、COPPA/政策雷区；`kill_conditions` 为必填输出 | 批式变体：分轮 + 提前终止条件参数化进循环；上一批的结构性发现注入下一批 brief 作为「必须逐条对照检验的假设」 |

## 测量教训（每条都付过学费）

1. **头词抽样低估矩阵市场 10–100 倍**；种子词语言错误制造数量级伪影（入籍考试用中文头词测美国市场 → 410/月，英文重测 → 101 万/月）。
2. **头词无 AI Overview 不能外推长尾**：moon/dream 头词干净、长尾探针 4/4 被直答。可靠安全区只有两类——**工具意图**（AI 不会替你算表格/生成文件）与**视觉产出**（摘要放不了可打印图）。探针要打在长尾上，且必须做阳性+阴性双向对照验证检测器本身。
3. **高 CPC 是负向信号**：说明词族被 SaaS/lead-gen/联盟盯死（一个访客对它们值 $50+ LTV，对广告站值 $0.01），SERP 位在经济学上不可进入。验证方式：实拆前排每一席的变现方式，数「广告站活体」个数。
4. **排名≠流量**：死词族里排第一也是零（typingtom 在 2 个探针词排第一、30 访问/月）。
5. **新站分布是双峰**：要么爬出沙盒（数千到数十万/月），要么永远 ~30 访问/月；沙盒期 6–12 个月。规划必须按命中率（实测 ~40–50%）而非均值。
6. **负向结论必须给测量口径**：Google Ads 对受限词类（玄学等）返回 None ≠ 无需求（走 Labs clickstream 替补）；大陆受众的 Google 数据分母无效（百度市场）——标注单列，不混入排名。

## 战役 #2（B2B 数据订阅）增补教训（2026-08-18）

7. **「企业价保护伞」是系统性模式**：数据类在位者普遍电话报价+年合同（$3k–25k/年），其价格地板下方 $49–299/月自助档大面积真空。判别信号：官网无价目页 / demo-gated / "contact sales"。这个空隙由行业销售模式产生，不会自动关闭。
8. **跨模态重复发现率是需求热度信号**：104 条去重街道中 24 条被 ≥2 个独立模态发现——交叉发现的候选进 Stage 3 的比例显著更高（战役 #1 同样成立：19/228）。
9. **Stage 2 可以 $0 完成**：订阅模式下付费意愿用「可比产品实抓价目」做代理，不需要任何 API 测量；打分用锚点表 + 批式 agent（7×15，读单元文件）一致性够用，主 agent 终审。
10. **让 Stage 1 agent 自标关闭**：允许并鼓励 agent 把查证后确认关闭的候选标为 `[已关闭-记录用]` 而非静默丢弃——既保持 glass-box（记录为什么关），又省下 Stage 2/3 成本（战役 #2 有 6 条自标，全部在打分层零成本确认 kill）。
11. **对同一片数据源，变现模式决定生死**：同一批政府数据在广告模式下全军覆没（战役 #1 移民集群死于窗口），在订阅模式下 82/104 存活——扫描前先定变现模式，不同模式需要不同评分卡。

## 战役 #3（跨市场套利）增补教训（2026-08-18）

12. **melting-ice 对新域名不可投资，但可页面级预占位**：语言滞后窗口（1–2 年）减去沙盒（6–12 月）后剩余收割期太短，不值得为其立项/买域名；正确做法是从第一天就把 melting-ice 信息页挂在工具锚定的站上当附属页（页面与域名一起养），窗口若在则收割、不在则零损失。纪律：站点必须工具页为核、信息页为辅，比例失衡会触发 AI 内容农场分类。
13. **域名时钟应尽早启动**：搜索沙盒的「年龄」主要从首次被抓取/索引起算而非注册日——确认名单后应立即买齐域名并部署最小可索引桩站+提交 GSC，让域名在建站队列排队期间就开始积累历史。即时制购买省下的 ~$10×死亡率是伪节约（期望损失总要发生），换不来时钟提前的真实收益。
14. **AI Overview 语言滞后是可测量的**：用同一探针管道按 locale 测——实测日语 25%、沙特阿语 23%、美西语 45%（vs 英语头词 28%）。美国 SERP 对西语与英语同步铺开=美西语无窗口；跨语言套利的 AI 抗性必须逐 locale 实测，不能从英语判决外推。
15. **同产品跨语言版本共用域名**（/ja/ 路径 + hreflang）：继承已熬沙盒的域名信任，是唯一能跳过沙盒税的扩张方式；不同产品才用新域名（风险隔离+kill 纪律+可分割变卖）。

## 战役 #2 Stage 3 增补教训（2026-08-18，现场数据 spike 后）

16. **spike 双向翻案，纸面 access_tier 不可信**：8 单元中 4 个被现场实测翻案——「敌对门户」两次实为开放数据（cannabis：CA 门户底下是 2 万条免鉴权 JSON API；restaurant：CA ABC 免登录日更 CSV 含 DBA 品牌名），「干净 bulk」两次干净到没有护城河（orange-book、warn）。尽调必须真拉源头样本，不能从门户外观/文档推断。
17. **「源太干净」是护城河死亡信号，三种形态都实测出现**：Wayback 月度快照一键重建「独占历史」（orange-book 58 个快照回溯 2019）、无鉴权 API 让 agent 按需拉（cannabis）、官方自己存档历史（state-facility）。「官方只显当前状态=存档独占」主张必须先查 Wayback 和官方历史快照页再采信。
18. **agent 替代性威胁已商业化**：WARN Firehose 已在卖 MCP server 直供 AI agent——「2027 浏览器 agent 吃掉窄范围 lookup/监控」不是预测而是现状；lookup 层一律按零价值估，能收费的只剩告警时效+纵向历史+工作流集成。
19. **Stage 4 通用门槛：访谈先于爬虫**——任何订阅数据产品动工前，先向 15–20 个目标买家发真实样本（spike 拉到的数据即可做样本），30–45 天拿不到 3 个付费（预）承诺 → 杀。爬虫工程在预承诺之后才写。

## 战役 #3 Stage 3 增补教训（2026-08-25，战役判负收官）

20. **CPC 幽灵价**：Ads API 返回的 CPC 对利基词不可信——amidakuji $4.9、マイクテスト $6.8 实查真实 SERP 均为**零广告主**（无人真的按此价买量）。收入算式用 CPC 前必须实查该词 SERP 是否真有投放广告；无广告主的 CPC 只是历史噪声或跨词族污染。
21. **竞争层先于窗口层**：语言滞后窗口（AI-OV 逐 locale 实测 ja 25%/ar 23%）真实存在，但对建站决策不充分——9 个 70 分附近单元尽调后 8 个死于**竞争层已饱和**：本地原生站（zakhrafa 的现代重建者 2026-05 注册 3 个月进前 5）+ 国际农场机器本地化皮（ja/ar/es 全部渗透）。跨语言套利的正确姿势只剩一种：已上线域名加 locale 路径（近零成本搭载），独立立项形态全灭。
22. **「更好的产品」不是杠杆**：mojisuu.com（功能全面超越在位者、已过沙盒）被挡在前 20 之外且流量 -55%；getfreeqr.app/ja 占住了差异化定位仍进不了前 10。对工具类 SERP，域名年龄+信任叙事碾压产品功能差距——「做个更好的」在 2026 不构成进入策略。

## 2026 行业结构判断（免费站+广告模式）

- **三重绞杀**：AI Overview 按意图分层吃流量（信息意图死亡通道，Pew 口径点击 15%→8%）；SERP 头部被非广告变现者百倍出价锁死；AI 建站克隆潮打崩裸 pSEO 边际收益（打法公开教程化 → 9+ 克隆互撕）。
- **各品类第一名的实测天花板普遍 $100–1,300/月**——中位数是爱好级收入；time.is 是幸存者偏差极端个例（原型 open-exam-prep 实测第 15 个月 $733/月）。
- **真护城河只剩三种**：习惯性直连流量（日刷/书签）、opt-in 数据网络效应、平台无法复制的授权/实体门槛。页面矩阵年龄在 AI 直答面前不再是资产。
- **窗口是易逝品**：mycaseshub 用约一年做到 23 万/月——论题对但晚到 12–18 个月照样出局。这反过来论证「便宜探针、快测快弃」。

## 决策框架

**30 秒预筛三问**（可杀掉 90% 的新想法）：
1. SERP 前排是谁、每访客赚多少？（lead-gen/联盟/订阅在位 → 出局）
2. 需求是信息、交易、还是工具/产出物？（前两者出局：信息被 AI 吃、交易需双边市场/库存数据）
3. ChatGPT 一句话能否满足？（能 → 流量是租来的）

**组合经济学要点**：现金平衡点 ≈30 PV/天（不构成筛选）；N 被三约束卡在 15–40（AdSense 单账号对 Google 完全可见+scaled abuse 政策反 N、利基质量递减、维护小时线性且资本买不回时间）；正确形状=**宽度探索、深度收割**（一个域名万级页面是正常深站，千站群是打击对象）；时间按资产口径定价（广告站 30–42x 月利润交易）；里程碑门控（Phase 1 实测自己的命中率，12 个月 <$30/h 转收割）。

## 技术速查（DataForSEO）

- 计价实测（2026-08）：search_volume $0.09/任务（**flat，与词数无关**，单任务 ≤1000 词）；SERP live advanced $0.002/条（AI Overview 检测需 `load_async_ai_overview: true`）；keywords_for_keywords ≈$0.09/任务。响应自带 cost 字段——放量前先跑 10 词实测再外推。
- 账号限速 12 请求/分钟（循环 sleep 5.4s；失败重试带 15s 退避）。
- 语言映射坑：Google Ads 无 `zh`（用 `zh_CN`/`zh_TW`）、无 `ne`/`pa`（降级近似并标注）；SERP 语言表与 Ads 不同（跑前拉 languages 端点做映射）；关键词禁特殊符号（`§ ⇄ '` 等需 sanitize）。
- 全套可复跑脚本在 `adhoc_jobs/traffic_goldrush/run_*.py`（采集/探针/扩展/打分）。

## 已知边界

- 本方法论只验证了 SEO 获客路径；社交分发（TikTok/Pinterest 为主渠道）、App、双边市场未覆盖。
- 流量估计器（SimilarWeb 免费口径/statshow 等）互相冲突是常态：多源交叉、记录口径、小站「无数据」本身是信号；statshow 对新站常给失效读数。
- RPM 全部用公开口径推算，未经自有站实测校准——Phase 1 探针的实测 RPM 回填后应更新本文件。
